VMS visits remain in the prototype store

!

Native Visitor sync status not yet verified

The operation requires a 5.11 Directory, Visitor Management licence, and explicit startup opt-in. It assigns no credential, escort, group or access rights. Use only approved non-production synthetic bookings.

→

Native visitor lifecycle

Native Visitor upsert is idempotent. Check-in and checkout only count as verified after the bridge returns the same Visitor GUID and native SDK read-back confirms the state. Credentials, escorts and access-rights mapping remain out of scope.

Connection is only marked live when the bridge returns a valid response. A failed network call never falls back to displaying fabricated server data.
